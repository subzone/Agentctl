MCP serveri

Proširi agente eksternim alatima preko Model Context Protocol-a. Stdio JSON-RPC, automatsko otkrivanje, name-spejsovano. Bez ručnog vezivanja žica.

Kako to radi

Ukaчi bilo koji MCP server

Definišeš server u Markdown fajlu, referenciraš iz agenta — alati se sami pojave. Bez magije, samo standardi.

examples/mcp/jira.md
--- name: jira type: mcp_server transport: stdio command: - mcp-server-atlassian - --jira env: JIRA_URL: ${env:JIRA_URL} JIRA_TOKEN: ${secret:jira-token} tool_prefix: jira ---

Tri koraka i radi

  • Instaliraj MCP server binary (pip, npm ili go install)
  • Napravi .md fajl sa parametrima
  • Dodaj mcp: [jira] u frontmatter agenta

Alati se name-spejsuju (jira__get_issue) da se ne sudaraju. Agent automatski otkrije šta server nudi preko JSON-RPC handshake-a. Bez tvog miksanja.

Kompatibilno

MCP serveri zajednice koji rade sa AgentCTL

Bilo koji stdio MCP server radi. Evo onih koji se dobro slažu sa agentima.

kubectl
Strukturirane Kubernetes operacije — status pod-a kao JSON, sigurnost na delete-u, scope po namespace-u.
Zajednica
Terraform
Parsiranje plana, inspekcija stanja, upiti nad graf-om resursa. Strukturirano umesto sirovog teksta.
Zajednica
Slack
Šalje poruke, čita kanale, pretražuje istoriju. Korisno za notifikacije i ChatOps. Bez emoji-poplave.
Zajednica
PostgreSQL
Upiti nad bazom, inspekcija šeme, izvršavanje migracija. Read-only mod za sigurnost — da ne obrišeš tabelu.
Zajednica
Docker
Upravljanje kontejnerima, inspekcija slike, stream logova. Lepo se slaže sa DevOps agentima.
Zajednica
AWS
CloudFormation, S3, Lambda, ECS operacije. Strukturirani odgovori za infra agente.
Zajednica
Brave Search
Web pretraga za agente koji moraju da pogledaju dokumentaciju, API ili neku aktuelnu informaciju.
Zajednica
Email (SMTP)
Slanje mailova, čitanje inbox-a. Korisno za notifikacije i izveštaje. Da te ne zovu kolege.
Planirano
HTTP/SSE transport
Mnogi MCP serveri koriste HTTP umesto stdio-a. Podrška dolazi u nekom budućem release-u.
