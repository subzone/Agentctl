Česti problemi, kako da ih rešiš, i gde da tražiš pomoć kad zaista zapne. Pre toga — restartuj jednom, oboje znamo.

Rešavanje problema

Česti problemi

Ollama daemon nije dostupan

Wizard ne može da se zakači na Ollamu na localhost:11434. Pokreni je ručno:

# macOS
brew services start ollama

# Ili jedan pokret
ollama serve

Za udaljenu Ollamu: export OLLAMA_HOST=http://host:11434

API ključ nije pronađen

Provajder ne nalazi ključ u OS keychain-u. Pokreni wizard da ga sačuvaš:

m init

Ili setuj env varijablu direktno: ANTHROPIC_API_KEY=sk-ant-... m. Ali ne commituj fajl sa ključem, mooolim te.

macOS Gatekeeper upozorenje

.pkg je nepotpisan. Desni klik → Open da zaobiđeš, ili:

xattr -d com.apple.quarantine ~/Downloads/m_*.pkg

Validacija agenta pala

U frontmatter-u nešto fali ili je krivo. Lintuj ga:

m validate moj-agent.md

Tipični uzroci: nedostaje name, type ili model; model nije u formatu provider/model; nepoznato polje (typo). Pa pročitaj poruku, tu piše šta fali.

secret-tool nije pronađen (Linux)

Instaliraj libsecret za podršku keychain-u:

# Debian/Ubuntu
sudo apt-get install libsecret-tools

# Fedora
sudo dnf install libsecret

# Arch
sudo pacman -S libsecret
