Instalacija

Jedan binary. Bez zavisnosti. 30 sekundi do prvog razgovora. Ako si tu, već znaš šta radiš.

1

Skini .pkg

Univerzalni binary (Intel + Apple Silicon) iz najnovijeg release-a. Bez DMG-a, bez gluposti.

Skini .pkg
2

Dupli klik za instalaciju

Instaler ubacuje m u /usr/local/bin/m. Ako macOS Gatekeeper baci upozorenje (nepotpisan .pkg), desni klik → Open, ili:

xattr -d com.apple.quarantine ~/Downloads/m_*.pkg
3

Pokreni čarobnjaka

Prvo pokretanje otvara setup wizard — biraš Ollama (lokalno, besplatno), Anthropic, OpenAI, Gemini, Alibaba ili LiteLLM. Ne moraš ništa da znaš unapred.

$ m

# Izaberi backend, nalepi API ključ (ili preskoči za Ollamu), gotovo.

Provera

$ m --version
m version 0.0.17
1

Skini .deb (Debian/Ubuntu)

$ wget https://github.com/subzone/Agentctl/releases/latest/download/m_0.0.17_linux_amd64.deb
$ sudo dpkg -i m_*_linux_amd64.deb

Za ARM64 (Raspberry Pi, Graviton): uzmi _linux_arm64.deb umesto. Ne mozak ne zatvaraj — i Raspberry Pi je računar.

1

Ili tarball (bilo koja distribucija)

$ wget https://github.com/subzone/Agentctl/releases/latest/download/m_0.0.17_linux_amd64.tar.gz
$ tar -xzf m_*_linux_amd64.tar.gz
$ sudo mv m /usr/local/bin/
2

Pokreni čarobnjaka

$ m

# Wizard instalira Ollamu ako biraš lokalno, ili pita za API ključ.

Provera

$ m --version
m version 0.0.17
1

Kloniraj i buildaj

Treba ti Go 1.26+. Ako nemaš Go, šta uopšte radiš ovde?

$ git clone https://github.com/subzone/Agentctl.git
$ cd Agentctl
$ go install ./cmd/m
2

Dodaj u PATH

Binary se sleti u $(go env GOPATH)/bin/m. Postaraj se da to bude u PATH-u.

$ export PATH="$PATH:$(go env GOPATH)/bin"

Provera

$ m --version
m version dev

Buildovi iz izvora pišu dev umesto verzije. Tako i treba.
