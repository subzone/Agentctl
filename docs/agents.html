Advanced

Agent Features

Fallback Models

When the primary model returns 429 (rate limit), the agent automatically tries the next model in the list.

fallback:
  - anthropic/claude-haiku-4-5-20251001
  - openai/gpt-4.1

Thinking Phrases

Customize the spinner text shown while the agent works. Useful for non-English agents.

thinking_phrases:
  - "razmišljam"
  - "čekaj bre"
  - "tražim bug"

Build your own agent

Any Markdown file with YAML frontmatter works. Start from an example and customize.
